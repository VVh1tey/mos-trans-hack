# Диспетчерская городского транспорта

## Platform

web

## Stack

React, TypeScript, Vite, MapLibre GL JS; Python backend, Docker Compose, nginx.

## Users

Диспетчер всей сети и диспетчер конкретного маршрута. Оба следят за транспортом,
отклонениями и свежестью данных, находят проблемы и оценивают выпуск дополнительного ТС.

## Capabilities and Constraints

Обзор сети, каталог маршрутов, маршрут, инциденты, история, What-if и настройка
порогов риска. Клик по маршруту открывает подробности на текущей странице; кнопка
«Перейти» открывает маршрут в новой вкладке. Несколько маршрутов можно добавить
звёздочкой в избранное; они показываются первыми в каталоге и сохраняются между вкладками.
В разделе «Сеть» отдельный блок NDTP запускает и останавливает предоставленный
симулятор и показывает через HTTP API живую телеметрию принятого TCP-потока:
статус отправки и приёма пакетов, позиции устройств на карте, скорость, время
пакета и свежесть данных. После остановки последние позиции сохраняются и
помечаются устаревшими при отсутствии новых пакетов.
Устройства симулятора пока не сопоставлены с ТС и маршрутами; маршруты, прогнозы,
инциденты и What-if остаются отдельно обозначенной демонстрацией.
Реальный инференс, Redis Stream и архивирование потока NDTP не подключены.

## Evidence on Hand

Интерфейс использует светлую бордово-графитовую палитру. data/additional содержит геометрию 18 ночных
маршрутов и справочник остановок; связь этих маршрутов с ТС обучающего датасета не установлена.
What-if — явно обозначенный демонстрационный расчёт, не обученная модель.
