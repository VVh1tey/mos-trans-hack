# ML

`train.py` запускает модуль из `experiments/`, вычисляет MAE на test и записывает отдельную папку в `runs/`. Примеры: медианная и средняя поправка к `cur_dev_s`. `compare.py` строит индекс запусков, `select.py` выбирает JSON-модель для онлайн-сервиса. Полный порядок действий и интерфейс нового модуля — в [инструкции](../docs/experiment-workflow.md).

`service.py` обслуживает `POST /predict` и читает `runs/selected.json`. До выбора модели используется `cur_dev_s` без поправки. Для CatBoost или иной модели потребуется обновить адаптер инференса и обеспечить одинаковые признаки в обучении и онлайне.
