# Frontend

Панель диспетчера: React, TypeScript, Vite и MapLibre GL JS. Первый экран показывает актуальные прогнозы, время обновления и состояние данных; затем карту и детали ТС/остановки. API/SSE согласуйте в `../contracts/`.

Создавайте приложение здесь. С первым рабочим экраном добавьте команды установки и запуска. `node_modules/` и `dist/` исключены из Git.

До появления React приложения Compose показывает статическую страницу из `mock/`. Замените её рабочим интерфейсом, сохранив проксирование `/api/` через nginx или согласовав новый маршрут.
