# Диспетчерская

React + TypeScript + Vite + MapLibre GL JS. Три экрана из `references/`: обзор сети,
маршрут и What-if; также каталог, инциденты, история с CSV-экспортом, настройки и карточка ТС.

На странице «Сеть» добавлен блок «Симулятор NDTP»: запуск/остановка предоставленного эмулятора,
карта принятых GPS-позиций, скорость и свежесть телеметрии. Для него нужен Docker-профиль `emulator`.
[Запуск и проверка реального потока](../docs/ndtp-simulation.md). Прогнозы и маршрутные показатели ниже пока демонстрационные.

## Локальный запуск

Из корня проекта, терминал 1:

```powershell
python backend/app.py
```

Терминал 2:

```powershell
cd frontend
npm ci
npm run dev
```

Открыть **http://127.0.0.1:5173**. Python 3.12+, Node 22.12+.
Docker, ML, Redis и PostgreSQL для фронтенд-демо не нужны.
Для другого адреса API задать `API_PROXY_TARGET` перед запуском Vite.
Backend поддерживает `HOST` и `PORT` (по умолчанию `0.0.0.0:8000`).

Полный контур из корня: `docker compose up --build -d --wait`.
Фронтенд **http://localhost:18080**; production assets собираются Dockerfile и
обслуживаются nginx, `/api/` остаётся на том же origin.

## Демо-сценарий

1. Обзор сети: карта 18 маршрутов и 123 тестовых ТС, метрики и срочные инциденты.
2. Кликнуть маршрут в таблице или линию на карте — справа откроются подробности.
   Кнопка «Перейти» в карточке открывает страницу маршрута в новой вкладке.
3. Нажать звёздочку у маршрута — добавить в избранное. Можно выбрать несколько;
   они сохраняются между вкладками и показываются первыми в разделе «Маршруты».
4. Открыть ТС с карты или из инцидента; просмотреть прогноз, отметить просмотренным.
5. В What-if задать параметры выпуска, рассчитать, сравнить интервалы и риски.
6. В настройках изменить пороги/цвета; backend пересчитает категории и KPI.

Фильтры, маршрут, направление и период хранятся в URL. Избранное и отметки просмотра —
localStorage. Клавиатура поддерживается; Escape закрывает карточку ТС.
«Просмотрено» — личная пометка, чтобы отличать открытые инциденты. Она не подтверждает
устранение задержки и не меняет прогноз; пометка хранится в этом браузере.

## Данные

HTTP-моки находятся в `backend/dashboard.py`, а не в компонентах React.
[Контракт и определения метрик](../contracts/dashboard.md).
Снимок создаётся при старте API; запросы сохраняют те же позиции и прогнозы.
Свежесть уменьшается с возрастом пакетов. Для нового снимка перезапустить API.
What-if — демонстрационная формула, не обученная модель.

`backend/demo/routes.json` включён в репозиторий: запуск не требует `data/`.
Геометрия — исходные линии из `data/additional/data-62904-11-08-2026.json`.
Остановки — ближайшие реальные точки из `data-60662-22-09-2026.csv`, порядок приближённый.
ТС и расписания синтетические. Днём тоже показывается демонстрация ночной сети.
Пересоздание fixture из исходников: `python scripts/prepare_dashboard_data.py`.

Подложка OpenStreetMap требует интернет. Для своего raster XYZ провайдера можно
задать `VITE_MAP_TILE_URL` при сборке и обновить атрибуцию в TransportMap.
Для массового production нужен подходящий тайловый сервис;
[политика публичного OSM](https://operations.osmfoundation.org/policies/tiles/).
WebGL2 необходим только для карты; при его отсутствии таблицы остаются доступны.
Worker собирается локально через Vite по [инструкции MapLibre](https://maplibre.org/maplibre-gl-js/docs/guides/v5-to-v6-migration-guide/).

## Проверки

```powershell
cd frontend
npm run build
npx playwright install chromium
npm run test:e2e
# из корня:
python -m unittest discover -s backend -p 'test_*.py' -v
docker compose config --quiet
```

При системном прокси: `$env:NO_PROXY='localhost,127.0.0.1'` перед тестами.
E2E: новая вкладка, карта, закрепление, карточка, What-if, настройки, экспорт,
мобильное переполнение, восстановление после отказа API.
Снимки: `.impeccable/review/` (не входят в Git).
